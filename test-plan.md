# Test Plan

## Purpose
Compare control concrete with concrete containing a compatible hydrophobic admixture using documented, repeatable laboratory methods.

## Before testing
- [ ] Faculty guide approves the mix design and testing procedure.
- [ ] Applicable standard and edition are recorded.
- [ ] Product technical data sheet and SDS are reviewed.
- [ ] Equipment calibration/status is checked.
- [ ] Specimen IDs and replicate count are planned.
- [ ] Acceptance criteria are defined before results are reviewed.

## Specimen preparation
- [ ] Record material sources, masses, batch date and mix ID.
- [ ] Record admixture product and exact dosage/units.
- [ ] Keep control and modified batches comparable.
- [ ] Record workability and any mixing/compaction problems.
- [ ] Label specimens clearly and photograph them.
- [ ] Cure under documented comparable conditions.

## Laboratory tests
- [ ] Conduct water absorption test using the selected applicable standard.
- [ ] Conduct compressive strength test at the planned ages using the applicable standard.
- [ ] Add other tests required for the intended pavement and exposure conditions.
- [ ] Record raw readings, calculations, units, test age and equipment.
- [ ] Record failed, damaged or excluded specimens and explain why.

## Analysis
- [ ] Report individual readings, replicate count, mean and variation where appropriate.
- [ ] Compare mixes only where methods and conditions are comparable.
- [ ] Calculate cost using documented quantities and current local prices.
- [ ] Discuss strength, workability, drainage, limitations and uncertainty.
- [ ] Do not label illustrative values as measured results.
- [ ] Base conclusions on results, not the expected outcome.

## Safety
Use appropriate PPE and follow laboratory safety rules, cement-handling precautions, equipment instructions and the admixture SDS. Only trained and supervised personnel should operate testing machinery.
